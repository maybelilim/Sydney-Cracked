# Sydney Loader Research (легаси 3.0.0, MC 1.21.4)

Заметки по реверс-инжинирингу и инструменты для **старого лоадера клиента Sydney**
(`sydney-loader.jar`, эпоха Minecraft 1.21.4 / Fabric 0.16.14, версия клиента 3.0.0).

> [!WARNING]
> Легаси-бэкенд (`/api/v1/loader/request`) **отключён (HTTP 404)**, старый домен
> `sydneyclient.xyz` больше не резолвится. Даже с полностью валидным ключом
> авторизации клиент 3.0.0 скачать невозможно. Репозиторий — документация
> схемы защиты в исследовательских целях.

## Что сделано

- [x] Полная деконструкция схемы защиты (пулы строк, диспетчер `D.i`)
- [x] Полный взлом локальной авторизации (`.sydney\authorization`)
- [x] Рабочий генератор ключей — лоадер принимает сгенерированные ключи
- [x] Документированы HWID-схема и анти-VM / анти-дебаг проверки
- [x] Восстановлен сетевой протокол (2 слоя шифрования, ChaCha20 + AES)
- [x] Инструментарий инструментирования (javassist offline-патчер + хуки вызовов)

владеете — см. отчёт и `.gitignore`.

## Кратко

| Параметр | Значение |
|---|---|
| Файл ключа | `%USERPROFILE%\.sydney\authorization` |
| Формат | `base64url( IV[16] ‖ AES-256-CBC-PKCS5(plaintext, K, IV) )` |
| KDF | PBKDF2-HMAC-SHA256, 100 000 итераций, 256 бит — **хардкод** пароля и соли |
| HWID | `SHA-256(os.name, os.arch, os.version, PROCESSOR_*, MAC)` |
| Анти-VM | Чёрный список MAC-префиксов: Parallels, VMware, VirtualBox, QEMU |
| Анти-дебаг | Анализ аргументов JVM (`javaagent`, `Xdebug`, ...) |
| C2 endpoint | `POST /api/v1/loader/request` — **мёртв (404)** |
